# sort_algorithms

This folder contains the following completed sorting algorithm implementations:

- `bubble_sort.js`: Bubble Sort with early exit optimization.
- `selection_sort.js`: Selection Sort with in-place minimum selection.
- `insertion_sort.js`: Insertion Sort with sorted-left insertion.
- `merge_sort.js`: Merge Sort with recursive divide and merge.
- `quick_sort.js`: Quick Sort with pivot partitioning.
- `heap_sort.js`: Heap Sort with in-place max-heap construction.

Each file includes:

- A plain-language explanation of how the algorithm works.
- Time and space complexity details.
- Edge case checks for invalid input.
- Example usage.
